# Native companion surface classification

Run `dotnet run --project tests/CompanionSurfaceTests -c Release` from the repository root.

The source-linked fixture uses the installed API's `AtkUnitBase` and `AtkCollisionNode` in synthetic stack memory. It checks null, empty, invisible and draw-disabled headers; ordinary window containment; and the exact `ToDoList` open-strip exception even when a dummy header is present. Fixed native names are read within their span. No native game function, game process, profile or network is accessed.

The existing `CompanionPhysicsTests` cover walking off both open-strip edges; `CompanionBehaviorTests --surfaces-only` covers actual synthetic ImGui window classification and expiry.
