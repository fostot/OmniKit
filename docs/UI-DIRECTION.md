# UI direction

OmniKit uses a quiet charcoal surface, cream text and a single warm gold accent, with a moon companion as its visual anchor.

The launcher puts one query above a scrollable result list. Settings use four plain-language sections and reveal controls only when a feature is enabled. First run explains the local command matcher before offering optional AI.

Motion is limited to a slow companion bob and native hover/focus feedback. Animation and the companion can both be disabled. All growing content lives in scrollable regions; footer space is reserved separately. The core window minimum is 600 x 480 logical pixels and settings minimum is 620 x 500, scaled with Dalamud's UI scale.

Umbra's widget uses Umbra's own theme, icons, menu and dimensions. Runtime game screenshots remain part of the acceptance checklist.
